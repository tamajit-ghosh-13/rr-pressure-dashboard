CRITICAL DATA TRAP Gate D1

The `extras1_runs` Trap & Resolution

In raw ball_by_ball.csv, extras1_runs is a delivery type code (wide=2, bye=4, legal=6), NOT additive runs. Naive summation adds +6 runs to every legal ball.

• Summing extras1: 5.2 run error
• Gate D1 repaired: 2.6 run error
EMPIRICAL ABLATION Plateau [1.0, 3.0]

Symmetric Wicket Sweep ($W_{\text{val}} = 2.50$)

Batters are penalized 2.50 runs per dismissal above expected; bowlers receive 2.50 runs credit. Across $W \in [1.0, 3.0]$, Top-10 overlap is stable (≥80%) and reliability flat ($\rho \approx 0.26$ to $0.28$).

• W=0:Ignores dismissals
• W≥6: Variance collapse (ρ=0.16)
• W=2.5: Calibrated Midpoint
